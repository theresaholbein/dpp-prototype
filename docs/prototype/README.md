# Klickbares Mockup

`Main.dc.html` (Web-App) und `Public.dc.html` (öffentliche Passseite mobil) sind die Quelldateien des Mockups „DPP-Modul – klickbares Mockup“ (Claude Design-Canvas, Stand 24.11.2026).

- Inhalte und Abläufe: verbindliche Vorlage (Ansichten, Felder, Demo-Daten in den Konstanten `PRODUCTS`, `FIELDS`, `DIFF`, `VERS`, `ROLES`).
- Aussehen: nur Annäherung. Verbindlich sind `docs/design-bible/` und `docs/reference/`.
- Format: HTML mit Vorlagen-Syntax (`{{…}}`, `<sc-for>`, `<sc-if>`) und einer Logikklasse im Skript am Dateiende. Nicht direkt lauffähig, nur zum Lesen.
